# 电池退化 · 本地拟合与追加检测设计工作台

一个**完全本地、离线运行**的单页应用：接通 CSV 导入 → 双阶段退化拟合与删失似然 →
轮廓似然可分辨性诊断 → 在可用时间窗口内设计下一次检测 → 接受建议并追加一轮合成测量 →
重拟合 → 审计“预测信息增益 vs 实际信息增益”的完整闭环。

面向的实际问题：不同电池批次的检测日程不同，几条退化曲线在观测区间内可能非常接近、
拟合优度都很高，但转折点和 L80 寿命的可分辨性差异很大。本应用不只报告 \(R^2\)，
而是用轮廓似然展示关键寿命参数到底能不能分辨，并给出有预算约束的下一步检测建议。

> 统计模型、公式与判定阈值的完整说明见 **[`MODEL.md`](MODEL.md)**；
> 应用内右上角“模型定义”有同内容的中文弹窗。

## 功能闭环

1. **数据**：五个预置场景（含固定随机种子的真值，可叠加真值曲线自检），或导入自己的 CSV。
2. **拟合**：规范的连续双阶段（hockey-stick）模型
   \(\mu=a-b_1t-(b_2-b_1)(t-\tau)_+\)，支持检测仪加性偏移、超量程/低量程删失似然。
3. **共享假设**：`a / b1 / b2 / tau` 可分别在 每单体 / 批次共享 / 全局共享 之间切换，
   切换后自动重拟合；可开关仪器偏移项、指定参考仪器、调整 EOL 阈值。
4. **可分辨性**：对寿命 L80、转折点 τ、b2、仪器偏移 δ 画轮廓似然，
   按 \(\Delta\mathrm{NLL}\le1.9207\) 给 95% 区间，明确标注
   可分辨 / 平坦不可分辨 / 单侧或双侧开放 / 区间过宽 / 轮廓不可靠。
5. **检测建议**：候选时间只来自数据提供的可用窗口；以删失感知 Fisher 信息 +
   Schur 补寿命方差预测“接受后寿命区间宽度”，并用真实轮廓宽度校准；
   同时报告信息矩阵秩诊断。样本破坏预算（演示数据为 3 个）为硬约束。
6. **接受与追踪**：接受建议后按当前拟合 + σ 生成一轮合成测量（含同样的量程截断），
   追加到图中并重拟合。建议创建时的排序、轮廓、预测宽度被**冻结**，状态变为
   已接受 / 因假设变更而失效；台账对比冻结预测增益与接受后实际轮廓增益，可反复重新评估。
7. **诚实的外推分级**：按寿命估计超出 \(t_{\max}\) 的程度分为
   已观测穿过 / 短期外推 / 较强外推 / 推测性外推，区间上界开放时明确提示
   “不能排除更长寿命”，绝不把远程外推写成确定结论。
8. **失败路径**：参数多于数据点等情形直接给出中文可行性错误（含自由度），
   不输出拟合曲线；另有专门的“数据不足”场景核对。
9. **界面**：原生 HTML/CSS/JS + 手绘 SVG，无 npm 构建、无外部 CDN/字体请求；
   支持深色模式、图表悬浮提示、数据表视图与响应式布局。

## 快速开始

需要 Python 3.10+（开发环境为 Python 3 + numpy/scipy/flask）。

```bash
cd /workspace

# 方式一：启动脚本（缺依赖时自动 pip install --user）
bash run.sh

# 方式二：手动安装依赖后启动
python3 -m pip install -r requirements.txt
python3 -m backend.server
```

然后浏览器打开 <http://127.0.0.1:8000>。

- `run.sh` 通过环境变量把服务绑定在 `HOST=127.0.0.1`；
- 直接运行 `python3 -m backend.server` 现在默认也只绑定 `127.0.0.1`；
  如需局域网访问可显式设置 `HOST=0.0.0.0`，端口可用 `PORT=9000` 更改。
- 应用不访问任何外部网络；前端库全部为本地静态文件。

运行测试：

```bash
cd /workspace
python3 -m unittest discover -s tests
# Ran 19 tests ... OK
```

## 预置场景

| ID | 名称 | 核对要点 |
|---|---|---|
| `standard` | 标准三批次（检测日程不同） | 不同巡检时间、少量超上限右删失；曲线接近但 L80 寿命不同；寿命轮廓为有限可分辨区间 |
| `knee_unobserved` | 转折点未观测 | 数据只覆盖一阶段，τ 轮廓平坦、双侧开放；建议自动偏好晚期 W4/t≈50 以进入二阶段 |
| `instrument_swap` | 检测仪更换（含系统偏移） | INST-B 系统偏低约 2.4，第 15 周有双机比对；开启偏移可恢复 δ 与 τ，关闭偏移可复现斜率被抬高、残差按仪器分组偏离的错误拟合 |
| `replicates` | 重复读数（同点 3 次） | 90 行重复测量数据，`repeat` 列可见；重复观测逐行进入似然 |
| `fit_failure` | 数据不足（拟合失败核对） | 3 个数据点对当前共享假设下 5 个参数，自由度 −2；显示可行性横幅，跳过拟合，轮廓不可计算 |

每个场景在 [`data/`](data/) 下也有同名 CSV，可直接用“导入 CSV”回放。

## CSV 数据格式

必需三列（中英文表头均可，别名见 `backend/engine/datasets.py` 的 `HEADER_ALIASES`）：

| 规范列名 | 可用表头示例 | 说明 |
|---|---|---|
| `cell` | `cell` / `单体` / `样品编号` | 单体 ID |
| `t` | `t` / `time` / `weeks` / `时间` / `检测时间` | 检测时间（数值，单位自洽即可） |
| `y` | `y` / `soh` / `读数` / `容量保持率` | 精确读数 |

可选列：`record_id/id/编号`、`batch/批次`（缺省归入 `?` 批）、
`instrument/检测仪`（缺省 `INST-A`）、`repeat/重复`、`censored/删失类型`、
`limit/量程界限`、`provenance/来源`。以 `#` 开头的行视为注释。

### 量程截断的两种写法

直接写在 `y` 单元格中（推荐）：

```csv
cell,t,y,instrument
A01,42,">=100",INST-A
A01,54,"<=60",INST-B
```

或拆列写：`y` 填界限值，`censored` 填 `right/超量程`（右删失，真值 ≥ limit）、
`left/左删失`（真值 ≤ limit）、`none`（精确），并用 `limit` 给出界限。

应用内“导入 CSV”对话框提供模板、文件选择、拖拽与粘贴；解析错误（如缺少必需列、
时间/读数不是数值）会逐条中文提示且不会关闭对话框。也可通过
`GET /api/template.csv` 下载模板。

## HTTP / JSON API 摘要

服务由 Flask 提供（[`backend/server.py`](backend/server.py)），页面与 API 同源：

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/scenarios` | 场景列表 |
| POST | `/api/session/scenario/<sid>` | 载入预置场景 |
| POST | `/api/session/import` | 导入 CSV 文本（`{"csv": "..."}`；有行错误时 422 并返回 `import_errors`） |
| GET | `/api/session` | 完整会话状态（数据、拟合、建议台账、预算） |
| POST | `/api/session/settings` | 修改共享作用域 / 模型选项 / 当前单体 / EOL |
| POST | `/api/profile` | 计算轮廓似然（`{"target": {...}, "n_grid": 21}`） |
| POST | `/api/recommend` | 创建并冻结一条检测建议 |
| POST | `/api/recommendations/<id>/accept` | 接受建议、追加合成测量并重拟合（预算/状态冲突返回 409） |
| POST | `/api/recommendations/<id>/reevaluate` | 用当前会话重新评估该已接受建议的实际增益 |
| POST | `/api/session/reset` | 恢复干净的标准演示场景 |
| GET | `/api/session.csv` | 下载当前会话数据（含合成行） |
| GET | `/api/template.csv` | CSV 模板 |
| GET | `/api/scenarios/<sid>/csv` | 下载某场景的原始 CSV |

所有改变会话的路由由进程内 `RLock` 串行化，避免双击/并发请求造成重复接受与预算穿透。
服务是单用户本地工具，没有鉴权层——请不要把 `HOST=0.0.0.0` 直接暴露到不可信网络。

## 诚实的限制

- 所有“新测量”都是**按拟合模型生成的合成数据**，用于演示设计—更新—审计流程；
  单次随机实现下“实际增益 vs 预测增益”会有抽样波动，界面会如实给出比值与解释。
- 轮廓区间依赖网格与局部约束优化；优化异常时返回 `unreliable` 而不是强行给区间。
- 远程寿命主要依赖双阶段线性这一模型形式，`speculative` 级别的寿命数字
  **不是确定结论**；区间上界开放时尤其如此。
- 模型不含单体随机效应、异方差、误差相关与异常点自动识别，详见 [`MODEL.md`](MODEL.md) 第 10 节。
